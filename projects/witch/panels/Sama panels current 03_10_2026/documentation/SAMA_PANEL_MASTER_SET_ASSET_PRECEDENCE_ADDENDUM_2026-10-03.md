# SAMA — PANEL MASTER / SET-ASSET PRECEDENCE ADDENDUM

**Date:** 2026-10-03  
**Status:** ACTIVE OWNER CLARIFICATION  
**Scope:** SAMA music-video / comic-panel scenery-continuity project only

## 1. Project boundary

This document applies only to the **SAMA suburban-house set**.

It does **not** modify the persistent technical `Dragon House` project.

SAMA set canon:

- the house is an almost ordinary suburban house;
- exterior doors and windows are human-scale;
- Dragon normally uses human form outside / around people;
- full Dragon form may be used privately inside the house;
- the purpose of environment and prop masters is visual continuity between panels.

## 2. Important precedence correction

Existing panel masters are **evidence and accepted story images**, but they are not untouchable architectural law.

If a later dedicated environment or prop master resolves continuity, scale, geometry, or repeatability better, the panel may be rebuilt.

Working precedence for scenery continuity:

1. explicit current owner decision;
2. current accepted dedicated environment / prop master;
3. accepted panel master as scene/story reference;
4. older drafts and discarded generations.

Therefore:

```text
panel master != immutable geometry
```

A panel may be re-rendered when doing so improves cross-panel consistency and preserves its narrative function.

## 3. How to use existing panel masters

Panel masters remain extremely valuable for:

- story meaning;
- object placement;
- lighting mood;
- camera logic;
- material language;
- relative spatial relationships;
- recurring environmental details.

But when a dedicated reusable set asset is approved, future panel work should prefer that asset for repeated architecture / props.

## 4. Current hearth example

`p18-00-master.png` remains the key source for the **idea and history** of the extinguished hearth:

- rough domestic masonry;
- dirty white plaster;
- wide dark firebox;
- soot;
- ash;
- charred logs;
- dying / extinguished state.

However, if `ASSET.PROP.HEARTH.001` is accepted by the owner as the canonical reusable hearth, then:

- that asset becomes the structural source for future hearth appearances;
- P18 may be rebuilt later using the accepted hearth asset;
- later P21 / P25 / P26 / P28 / P30 should preserve the same hearth geometry while changing only fire state / scene dressing where possible.

## 5. Instruction to Shelest / panel artist

Do not distort a good reusable set solution merely to reproduce every accidental geometric detail of an older panel.

Preserve the panel's **story truth**.

Rebuild its set geometry when necessary so the SAMA house becomes one coherent place.
