# Knowledge Base

Shared technical and methodological knowledge intended to survive individual project chats.

Knowledge is separated from project-specific handoffs.

## Working status vocabulary

- `research/` — sourced investigation; useful but not necessarily locally verified.
- `proven/` — tested in the actual local workflow and accepted as a working baseline.
- `experiments/` — controlled tests that have not yet become baseline.
- `limitations/` — known restrictions, failures, incompatibilities or unresolved capability questions.

Do not silently promote research or an experiment into a proven recipe.
