# Handoffs

Durable continuity documents for sisters replacing one another or transferring a project role.

## Current classes

- `sama/` — SAMA project continuity
- `witch/` — WITCH project continuity
- `characters/` — character-production continuity
- `cross-project/` — handoffs whose primary purpose crosses project boundaries

## Rule

A handoff transfers context, provenance, observations, decisions, warnings and open state. It does **not** automatically transfer authority.

Historical material remains historical unless a current owner explicitly re-adopts it.
