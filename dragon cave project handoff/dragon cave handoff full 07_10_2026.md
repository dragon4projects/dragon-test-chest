# 8. CORE TOPOLOGY — HYBRID v0.2 → REV_B CANDIDATE

The preferred architectural synthesis combined:

```text
C = macro-growth / branching logic
B = local chambers / thresholds / partial sightlines
A = readable public-to-private semantic orientation
```

The core spatial sequence is legible but **not a mandatory corridor**:

```text
ENTRY → ARRIVAL → SHARED / SOCIAL → QUIETER TERRITORIES → DEEP PRIVATE
```

Important spaces:

### Arrival / Receiving

Threshold between outside and domestic life.
Supports luggage, temporary deliveries, guests, weather traces, entrance events.

### Common / Social

A destination, not a toll gate.
Supports hearth, common table, seating, gatherings, event mess, optional HOME_STATIC.
Residents can bypass it.

### Work / Study / Workshop Bay

A side destination, never a through-route.
Supports tools, papers/storyboards, archives/work surfaces and optional WORK_STATIC.

### Rest / Quiet

A quieter domestic destination. It must not become a distributor or compulsory route.

### Deep Private / Memory

Reached through a real privacy transition: bend, material/light/acoustic change, threshold chamber. Not merely a label at one end of a corridor.

### Artifact / Memory Branch

A dedicated branch exists, but memory is distributed through the House. It must not turn the whole House into a museum.

### Resident circulation

Resident/guest/pet movement is primary locomotion.
There is an edge/bypass spine with multiple vertical access points. The goal is optional social contact, route choice, privacy, future growth and reduced congestion.
